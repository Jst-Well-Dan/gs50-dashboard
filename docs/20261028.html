PE 优先用卖方共识 PE_NTM（A 股 40/41 家，共识快照 20261028；港股 0/13 家，共识快照 —），缺的退回 PE_TTM。 NTM = w×FY1 + (1−w)×FY2，w = 距本财年结束剩余天数 / 365；港股按各公司财年（阿里/联想是 3 月年结）算，港股 EPS 多为人民币， 按当日 CNYHKD 折成港元再比价，所以同一家会出现 NTM 与 Yahoo forwardPE（只取 FY1）的小差。 「量能」= 当日成交额 / 前 20 日均；「距60日高」= 收盘 / 60 日最高 − 1（0% 即新高）； 港股历史来自 —（约 400 根，新股只到上市日），当日快照补最后一根；港股共识 3 天刷新一次，Yahoo 限速时沿用上一份。

6估值：贵不贵 × 增速配不配

这两张是结构图，不是买卖信号：上图看「同一层里谁被定了高价」，下图看「这个高价有没有增速兜底」。 PEG 射线读法：线下方 = 增速配得上估值，线上方 = 贵；今天贴在最上方的三家（华虹 6.3、中芯 2.8、寒武纪 1.0 上下）就是「贵得有理由但也在透支」的位置。 增速是 FY2/FY1 的预测利润比值，低基数转正会把它放大到几百个百分点（沐曦 2225%、芯原 554%，已贴右边界的 ▸ 标记），那种 PEG 看着便宜并不作数。
