标签怎么算

板块中位 = 该股所属全部 AI 概念板块当日中位的均值；每个板块的中位由成分股当日涨跌算出 （data/em_cons.csv 的 12,729 条成分关系 × 通达信全 A 盘后包，含名单外成分）。悬停该格可看用了哪几个板块。

独走 / 共振 / 背离 = 个股涨跌 − 板块中位：差 > +2.5pt 记「独走」，< −2.5pt 记「背离」，中间记「共振」。

标签：|涨跌| / 60 日日波动 ≥ 1.8σ、量能 ≥ 1.8×、距 60 日高 > −1%、 距 250 日低 < 3%、涨停/跌停取行情字段——全部按当天数据算，阈值是代码里的常量。

「换手率」A 股用流通换手（行情接口口径），港股无流通盘数据，退化为成交额 / 总市值（口径偏小，只做同市场内比较）。

PE / 量能 / 距 60 日高 怎么算

PE 优先用卖方共识 PE_NTM（A 股 41/41 家，共识快照 20261117；港股 0/13 家，共识快照 —），缺的退回 PE_TTM。

NTM = w×FY1 + (1−w)×FY2，w = 距本财年结束剩余天数 / 365；港股按各公司财年（阿里/联想是 3 月年结）算，港股 EPS 多为人民币， 按当日 CNYHKD 折成港元再比价，所以同一家会出现 NTM 与 Yahoo forwardPE（只取 FY1）的小差。

「量能」= 当日成交额 / 前 20 日均；「距60日高」= 收盘 / 60 日最高 − 1（0% 即新高）。

「60日 / 今年以来」另换一套源：A 股用 data/kline/daily.csv 的前复权日线（约 260 根）， 港股用 hk/kline.csv 的除净后日收益连乘再补当日快照——盘后包只归档了 37 个交易日， 撑不起这两个窗口。今年上市的新股从上市首日算。

港股历史来自 tushare hk_daily（约 400 根，新股只到上市日），当日快照补最后一根；港股共识 3 天刷新一次，Yahoo 限速时沿用上一份。

7口径需要时展开

数据来源

这 54 家不是组合，是采样点——用它读 AI 这条线在中国的温度、广度、轮动和与概念板块的背离。

A 股 41 家用通达信盘后包（收盘价、成交额、涨跌停），市值 / PE_TTM / 换手 / 量比用 tushare daily_basic 的当日截面（20261117）； 港股 13 家：当日有腾讯快照就用快照（价格 / 总市值 / PE_TTM），历史日由 tushare hk_daily 未复权收盘还原； 动量 / 量能 / 走势用 hk_daily 日线；前瞻 PE 用 Yahoo 卖方共识； 基准用腾讯指数（沪深300 / 创业板指 / 恒生科技）； 成交额占比 = 名单（41 家 A 股）成交额 / A 股全市场成交额（不含港股）。

口径与基准（6 条）

① 名单：GS 三张表去重 54 家（A 41 / HK 13），不构成组合，页面里没有权重和归因。

② A 股行情：涨跌与成交额来自通达信官网盘后包（当日收盘口径，与交易所一致）；港股当日快照来自腾讯，5/10/20 日、量能与 40 日走势来自 tushare hk_daily。 层间强弱的净值曲线是另一套源：data/kline/daily.csv 的前复权日线（约一年）， 所以「今年以来 / 近60日」才有足够长的样本——盘后包只归档了 37 个交易日，撑不起这两个窗口。 两套源的差别只在除权除息日的一两个基点，斜率与排序不受影响。

③ 港股 PE：13 家前瞻 PE 来自 Yahoo 卖方共识（覆盖 1–32 家机构，小票只有 1–4 家，参考度弱于 A 股的 20+ 家）； 分层 PE 打点图里港股是空心点（口径相同、只标记市场），PEG 散点图暂不含港股——Yahoo 那份共识没有 FY1/FY2 明细，算不出增速。
