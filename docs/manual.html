01它是什么，不是什么

是：每天收盘后跑一遍流水线，把全市场盘后包 + 名单快照 + 共识 + 港股日线，算成一张单文件 HTML （温度 / 广度分化 / 结构轮动 / 名单 vs 板块 / 异动 / 全表 / 估值），并按日永久归档。

不是：不是组合，没有权重、没有回测、没有买卖建议。54 家是采样点，用来读「AI 这条线在中国的温度、广度、轮动与背离」。

一句话回答「港股能不能全用 tushare 取」： 能取价格与成交额（hk_daily，含未复权收盘），能取财报（hk_fina_indicator）， 但取不到「当日市值 / 当日 PE」——港股没有 daily_basic 那一层，常见说法里的 hk_dailybasic 在 Tushare 根本不存在（hk_daily_adj 同样没有）。 所以港股的市值 / PE 只能靠快照 + 折算，不能像 A 股那样按日期原样重取。

04港股：哪些是真值、哪些是折算、哪些拿不到

这是本页最需要说清的一段：历史日的 hk/<day>.csv 里，13 家的字段分三类。

字段历史日怎么来的类别
pricetushare hk_daily 的未复权收盘（不是前复权）真值
pct_chghk_daily 的 pct_chg（除净口径，含分红调整）真值
amount_yihk_daily 的成交额真值
ret5 / ret10 / ret20 / dist_hi60 / dist_lo250 / sigma60 / spark用本地价格序列重算真值
total_mv_yi收盘 × 20261030 快照隐含股本（快照市值 ÷ 快照价）折算
pe_ttm20261030 快照 PE_TTM × 市值比（净利视为不变）折算
pe_ntm20261030 快照 PE_NTM × 市值比（共识只有这一版）折算
hkd_cny沿用 20261030 的汇率（对 PE 影响 <1%）折算
turnover成交额 ÷ 总市值（港股没有流通盘口径）换算
n_brokers / cons_date / fy0_eps / fy1_eps / eps_ccy / fy0_end / yahoo_fwd_pe 留空——Yahoo 只给「当下」一版共识，历史版本无法回溯，也不许拿今天的共识冒充那天拿不到
float_mcap_yi留空——腾讯港股快照本身没有流通盘拿不到

实测校验（拿 20261030 的真实快照反算）：

  • 市值 = 未复权收盘 × 快照股本，与腾讯当天快照差中位 0.1%；
  • 00700 的 PE_TTM 38 期全程 16.12 → 14.01，逐日变化中位 1.3%，没有跳变；
  • 只有「快照日 vs 折算日」交接处会有一次小台阶（20261028 / 20261030 是真快照，其余是折算）。
为什么不用 hk_fina_indicator 的股本和 EPS 做「真值」？（点开看实测数据）

看起来更正确：hk_fina_indicator 里有 eps_ttm、issued_common_shares， 市值 = 收盘 × 真实股本、PE = 收盘 ÷ eps_ttm，全是财报口径。实测两个坑：

① 股本字段明显滞后。09903 天数智芯 的 issued_common_shares 只有 2.54 亿股， 按快照反推真实股本 8.07 亿股 → 用它算市值会错 −69%（新股增发后供应商没跟上）。

② EPS 口径与腾讯当日 PE 差 0–5%，个别标的更大。06082 壁仞科技 在 20261028 与 20261030 两份快照之间，供应商把 TTM 亏损口径改过一次，PE 从 −73.8 变成 −3.0。混用「财报 PE」与「快照 PE」， 会在快照日与非快照日的交界处留下台阶——比统一折算更难读。

结论：价格用真值、股本锚定一次、PE 按市值比折算，是这套数据里最不容易出错的组合； 这也正好是页面第 7 节「口径 · 数据来源」里那句「港股（日期，按收盘还原）」的意思。

05A 股：口径与历史回补

字段来源历史可回补？
收盘价 / 涨跌 / 成交额 / 涨跌停通达信盘后包（按日期下载，2024-12 的包都还在）可（原样重取）
总市值 / 流通市值 / 换手 / 量比 / PE_TTM / PBtushare daily_basic（按 trade_date）可（原样重取）
PE_NTM（GS 口径核心）tushare report_rc + NTM = w×FY1 + (1−w)×FY2可（按 as-of 日重算，不前视）
60 / 250 日高、40 日走势、σ60腾讯 qfq 日线可，但前复权会随除权重锚（微差）
板块中位 / 板块量能em_cons.csv（静态成分）+ 盘后包成分是静态基线，板块调整需重抓；第 3 节象限图的灰点只算名单内成分（与彩点同口径），表格里的板块中位是全成分（市场口径）

腾讯的 quote/ 快照只有「当下」一个时点，所以历史上曾经出现过「拿 10-31 的快照去算 10-30」的错位。 现在的规则是：先确认这天的盘后包存在，再让快照落盘；快照文件名永远等于「真有交易的那一天」。

06怎么重跑 / 怎么回补

# 一天（抓数 → 出页 → 归档；非交易日会自动退到最近交易日）
python scripts/run_daily.py
python scripts/run_daily.py 20261029
python scripts/run_daily.py --rebuild            # 不抓数，用已有 data/ 重出页面
python scripts/run_daily.py --rebuild --all       # 38 页全重出（约 3 分钟）

# 补历史：A 股估值
for d in $(ls data/mkt | sed 's/.csv//'); do python scripts/theme_data.py dbquotes $d; done

# 补历史：A 股共识（先联网把原始研报表缓存拉宽，再按日离线重算）
python scripts/fetch_consensus.py 20261030 --force --window=250
for d in $(ls data/mkt | sed 's/.csv//'); do python scripts/fetch_consensus.py $d --offline --force; done

# 补历史：港股（日线先补到最新，再由快照锚点还原每天）
python scripts/build_hk_kline.py 20261030 --force
python scripts/backfill_hk.py                     # 只补缺的交易日
python scripts/backfill_hk.py --all               # 已有真实快照的日子也补（只填空列）

流水线四步：①抓数（盘后包 → 回补历史 → 港股 → A 股快照 → 日线）→ ②共识（逐家研报，最慢） → ③出页（2 秒）→ ④归档（总览 + 门厅）。每一步都能单独跑，失败重跑不会写坏已有文件。

09已知缺口（按影响排序）

  1. 港股前瞻 PE 的机构覆盖薄：13 家都能算，但小票只有 1–4 家机构（天岳先进 1 家），腾讯 32 家、阿里 19 家。
  2. 港股历史市值 / PE 是折算：股本只锚定一次，期间增发 / 回购不反映；共识只有一版，历史 PE_NTM 不能回溯。
  3. Yahoo 会间歇限速（429）：共识按股票缓存 3 天，限速时沿用上一份并记 cons_date。
  4. A 股共识有 180 天新鲜度：个别小票研报稀疏，某天的窗口里可能一家机构都没有 → 该家退回 PE_TTM。
  5. 板块成分是静态基线（77 板块 / 12,729 条），东财调整板块时不自动跟随。
  6. 日线只留最近 260 根：一年半以前的日子无法重算动量（当前 3 个月完全够用）。
